2 Interactive Data Visualization with R Shiny

2.1 Project Overview

For the independent learning component of the Workflows course, I have chosen to develop my skills in interactive dashboard development using R Shiny.

My goal is to learn how to build an interactive application that allows users to explore and visualize biological data without needing programming knowledge.

This project will involve learning the fundamentals of R Shiny and independently applying them to a biological dataset.

2.2 Why I Chose This Skill

As a Life Sciences student specializing in Data Science for Biology, I am interested in combining scientific knowledge with communication and business-oriented responsibilities.

My career interests include advisory and client-facing positions within the Life Sciences industry, such as Solutions Consulting, Technical Sales, and Business Development.

In these roles, communicating complex scientific information to different audiences is an important skill.

I chose R Shiny because it allows me to transform data analyses into interactive applications that can be used by people without programming experience.

Since I already have experience with R and RStudio, I can focus on learning dashboard development rather than starting with an entirely new programming language.

2.3 Learning Objectives

During this project, I aim to:

  1. Understand the basic structure of an R Shiny application.
  2. Learn how to create a user interface using Shiny.
  3. Understand the principles of reactive programming.
  4. Create interactive visualizations with user-controlled filters.
  5. Independently develop a functional dashboard using biological data.
  6. Document and demonstrate the functionality of my application.

2.4 Learning Plan

I have allocated 32 hours to complete this project, including learning, development, testing, and documentation.

2.4.1 Learning Resources

I plan to use the official R Shiny documentation, tutorials provided by Posit, and practical examples to learn the fundamentals of dashboard development.

I will first follow introductory tutorials to understand the structure of Shiny applications and then apply this knowledge independently to a different biological dataset.

The dataset and specific biological application will be selected before development begins, ensuring that the project does not overlap with my Projecticum.

2.5 Demonstrating My Learning

To demonstrate the skills I have developed, I intend to create a functional interactive dashboard using a publicly available biological dataset.

The dashboard should allow users to explore the data through interactive filters and visualizations.

I will document the development process, explain the functionality of the application, and make the source code available through GitHub.

If possible, I will also publish the dashboard online so that visitors to my portfolio can interact with it.
